# 🌸 blog

김소월의 시 「진달래꽃」을 담은 작은 정적 페이지입니다.
한지(韓紙) 톤 배경과 명조체 타이포그래피로 시의 정서를 살렸습니다.

## 미리보기

| 구분 | 내용 |
| --- | --- |
| 배경 | 아이보리 한지 톤 `#faf6f0` |
| 포인트 색상 | 진달래꽃 색 `#d46a8f` |
| 폰트 | Noto Serif KR |

자세한 디자인 의도는 [design.md](./design.md)에 정리되어 있습니다.

## 실행 방법

별도 빌드 과정 없이 `index.html`을 브라우저로 열면 됩니다.

```bash
open index.html
```
